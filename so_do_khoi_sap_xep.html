BỘ SƠ ĐỒ KHỐI THUẬT TOÁN TIN HỌC

Tổng hợp sơ đồ khối trực quan chuẩn xác cho các bài toán kinh điển

PHẦN 1: BÀI TOÁN TÍNH TOÁN VÒNG LẶP (Giai thừa & Tính tổng)
1. Tính Giai Thừa: GT = n! GT = GT * i 
flowchart TD
    Start(["Bắt đầu (Start)"]) --> InputN[/"Nhập số tự nhiên n"/]
    InputN --> Init["GT = 1
i = 1"]
    Init --> Check{"i <= n ?"}
    
    Check -- "Đúng" --> Multiply["GT = GT * i
i = i + 1"]
    Multiply --> Check
    
    Check -- "Sai" --> Output[/"Xuất kết quả GT"/]
    Output --> End(["Kết thúc (End)"])
2. Tính Tổng: S = 1 + 2 + ... + n S = S + i 
flowchart TD
    Start(["Bắt đầu (Start)"]) --> InputN[/"Nhập số tự nhiên n"/]
    InputN --> Init["S = 0
i = 1"]
    Init --> Check{"i <= n ?"}
    
    Check -- "Đúng" --> Add["S = S + i
i = i + 1"]
    Add --> Check
    
    Check -- "Sai" --> Output[/"Xuất kết quả S"/]
    Output --> End(["Kết thúc (End)"])
PHẦN 2: BÀI TOÁN SẮP XẾP DÃY SỐ (Tăng dần & Giảm dần)
3. Sắp xếp Tăng Dần A[i] > A[j] 
flowchart TD
    Start(["Bắt đầu (Start)"]) --> InputN[/"Nhập n và dãy A[0..n-1]"/]
    InputN --> InitI["i = 0"]
    
    InitI --> CheckI{"i < n - 1 ?"}
    CheckI -- "Đúng" --> InitJ["j = i + 1"]
    CheckI -- "Sai" --> Output[/"Xuất dãy A (Tăng dần)"/]
    
    InitJ --> CheckJ{"j < n ?"}
    CheckJ -- "Đúng" --> CheckSwap{"A[i] > A[j] ?"}
    CheckJ -- "Sai" --> IncI["i = i + 1"] --> CheckI
    
    CheckSwap -- "Đúng" --> Swap["Đổi chỗ A[i] và A[j]"] --> IncJ["j = j + 1"]
    CheckSwap -- "Sai" --> IncJ
    IncJ --> CheckJ
    
    Output --> End(["Kết thúc (End)"])
4. Sắp xếp Giảm Dần A[i] < A[j] 
flowchart TD
    Start(["Bắt đầu (Start)"]) --> InputN[/"Nhập n và dãy A[0..n-1]"/]
    InputN --> InitI["i = 0"]
    
    InitI --> CheckI{"i < n - 1 ?"}
    CheckI -- "Đúng" --> InitJ["j = i + 1"]
    CheckI -- "Sai" --> Output[/"Xuất dãy A (Giảm dần)"/]
    
    InitJ --> CheckJ{"j < n ?"}
    CheckJ -- "Đúng" --> CheckSwap{"A[i] < A[j] ?"}
    CheckJ -- "Sai" --> IncI["i = i + 1"] --> CheckI
    
    CheckSwap -- "Đúng" --> Swap["Đổi chỗ A[i] và A[j]"] --> IncJ["j = j + 1"]
    CheckSwap -- "Sai" --> IncJ
    IncJ --> CheckJ
    
    Output --> End(["Kết thúc (End)"])

Quy ước chuẩn các khối đồ họa (Flowchart Standard)

Hình Ovan / Elip Bắt đầu (Start) / Kết thúc (End)
Hình bình hành Nhập dữ liệu (Input) / Xuất kết quả (Output)
Hình chữ nhật Thao tác tính toán / Gán biến / Đổi chỗ
Hình thoi Điều kiện so sánh rẽ nhánh (Đúng / Sai)
