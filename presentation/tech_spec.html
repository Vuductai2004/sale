Thuật Toán Khóa Giá Sàn ($P_{floor}$) & Deterministic Policy Defense

Bảo vệ biên lãi ròng bằng code logic cứng ngoài LLM & Quản trị FinOps Token

PRICING DEFENSE · TRANG 5/10

1. Bản Cân Kinh Tế & Thuật Toán Giá Sàn Toán Học ($P_{floor}$)

Công Thức Giá Sàn Bất Biến: 
P_floor = max((C + L) / (1 - r), P_base - D_cap)
Điều kiện: 0 ≤ r < 1; dữ liệu chi phí hợp lệ.
  • $P_{base}$: Giá niêm yết chính thức trên ERP.
  • $C$: Giá vốn COGS + Token AI 0.5-1 TWD + Bao bì đóng gói.
  • $L$: Biên lãi ròng tối thiểu bắt buộc trên mỗi đơn.
  • $r$: Tỷ lệ chi phí thanh toán cổng thẻ/ví điện tử.
  • $D_{cap}$: Hạn mức chiết khấu tối đa của sản phẩm.
Cơ Chế Giữ Chỗ Ngân Sách Nguyên Tử:
  • Khi khách đồng ý mức giá $P_{offered} \ge P_{floor}$, máy chủ khóa giữ chỗ ngân sách trợ cấp và tồn kho trong cơ sở dữ liệu.
  • TTL Khóa Giá 10 Phút: Phát hành Token chữ ký HMAC. Nếu khách không thanh toán trong 10 phút, báo giá tự động hủy và ngân sách hoàn về quỹ chung.
  • Ngăn chặn tình trạng nhiều đơn đồng thời cùng khai thác vượt ngân sách trợ cấp.

2. Cơ Chế Chặn Đứng Tấn Công Prompt Injection / Hack Giá Sàn

Lớp code logic cứng ngoài LLM (Deterministic Policy Engine) hoạt động độc lập tại API Gateway:

def verify_price_offer(sku, offered_price, customer_context):
    pricing_data = erp_client.get_pricing_and_cost(sku)
    cogs = pricing_data['cogs'] + FINOPS_TOKEN_BUDGET_TWD  # Đã gồm chi phí AI
    p_floor = max((cogs + MIN_NET_MARGIN_L) / (1 - GATEWAY_FEE_R), pricing_data['p_base'] - D_CAP)
    
    # CHỐT CHẶN BẢO VỆ CỐT LÕI - LLM KHÔNG THỂ CAN THIỆP
